Declare the recipe

Create requirements.txt

A requirements file records the packages the project needs. Anyone, including GitHub Actions, can install the same dependencies from this one small list.

▤ requirements.txt

pytest

The connection

When GitHub Actions runs later, it will read this same file and install pytest in its fresh environment.

Your exercise

Create the source and test files

Now create these two files yourself. The source file defines a small function, and the test file checks that it works. Run the test before moving on.

{ } src/main.py

src/main.py
def add(a, b):
    return a + b
tests/test_main.py 
from src.main import add

def test_add():
    assert add(2, 3) == 5
Run it
python -m pytest
Expected result

The test should pass. A passing test is a small but meaningful signal that the project is behaving as expected.

05

Standardize the routine

Create a Makefile

A Makefile gives the team memorable shortcuts for common commands. Everyone runs the same recipe, whether they are on a laptop or in CI.

⌘ Makefile · project root
Makefile 
.PHONY: install test

install:
    pip install -r requirements.txt

test:
    python -m pytest
Important

Makefile commands must begin with a real TAB character, not spaces. The code block visually shows indentation, but type Tab in your editor.

make install→make test

The commands will be ready to use after you add the source and test files in the next step.

06

Automate the check

Add GitHub Actions

GitHub Actions runs repeatable tasks in the cloud when code changes. Add this file at .github/workflows/test.yml.

.github/workflows/test.yml
name: Tests

on:
  push:
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: pip install -r requirements.txt

      - name: Run tests
        run: python -m pytest
Next step

The workflow is in place. In the next step, add the source and test files it will run.
